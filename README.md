
# Telegram Chat Analyzer

Python-приложение для мониторинга Telegram-чатов. Ищет сообщения об интернет-ограничениях, сбоях связи, недоступности цифровых сервисов и проблемах с VPN.

## Как работает

1. Загружает список чатов из Excel.
2. Получает сообщения через Telethon и передаёт их в LLM через OpenRouter.
3. Модель определяет релевантность сообщений и формирует краткое описание.
4. Отправляет найденные сообщения в Telegram через бота.
5. Сохраняет прогресс в JSON-файлах и повторяет цикл по расписанию.

Сообщения анализируются пакетами. При ограничении Telegram FloodWait сбор приостанавливается до окончания заданного времени.

## Технологии

Python, asyncio, Telethon, OpenRouter, Telegram Bot API, openpyxl и JSON.

## Запуск

Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install telethon openpyxl python-dotenv openrouter
```

Создайте файл `.env` рядом с `config.py`:

```env
TELEGRAM_API_ID=ваш_api_id
TELEGRAM_API_HASH=ваш_api_hash
OR_API_KEY=ваш_ключ_openrouter
OPENROUTER_MODEL=название_модели
BOT_TOKEN=токен_бота
TARGET_CHAT_ID=id_чата_для_уведомлений
```

Добавьте файл `15_региональных_чатов.xlsx` с листом `15 региональных`: ссылки на чаты должны находиться в четвёртом столбце. При первом запуске Telethon запросит авторизацию аккаунта.

Один цикл мониторинга:

```bash
python run.py
```

Периодический запуск:

```bash
python scheduler.py
```

Интервал, лимиты сообщений и промпт настраиваются в `config.py`. Для каждого чата сохраняется последний обработанный ID; при первом запуске нового чата берутся последние сообщения.

## Основные файлы

- `tg_collector.py` — сбор сообщений и управление прогрессом.
- `llm_processor.py` — анализ сообщений через OpenRouter.
- `telegram_sender.py` — отправка результатов через Telegram-бота.
- `excel_parser.py` — загрузка списка источников.
- `state.py` — сохранение состояния и обработанных сообщений.
- `run.py`, `scheduler.py` — запуск одного цикла и периодического мониторинга.

Файлы `.env` и `*.session` содержат данные доступа и не предназначены для публикации.
